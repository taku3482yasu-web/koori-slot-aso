リポジトリの main にはもう入っています。このフォルダは「何が変わったか」を見るためのものです。

## 内部処理の担当にお願いすること

**ありません。** イベントの名前・データは変えていません。

- カットインの色（期待度）は、今までどおり内部処理の `notice` の `cutin`（`color`）と `bonus:nerae`（`color`）で決まります。
- どのキャラを出すかは演出側が選びます。顔ぶれは色ごとに決まっているので、キャラで期待度は変わりません。

## 変わったところ（演出だけ）

1. **チャンスのカットイン（前兆中）と「こおりを狙え」に、こおりくん以外のキャラも出る**

   | 色 | 出るキャラ |
   |---|---|
   | 青・緑 | こおりくん・やすさん・たむさん・だけさん・ふるカワ |
   | 赤 | こおりくん・だけさん・おにおに・ともいし |
   | 金 | こおりくん・おにおに・ともいし・ふるカワ |
   | 虹 | こおりくん（「こおりいきていける！」） |
   | こおりを狙え | こおりくん・おにおに・やすさん・たむさん・だけさん・ふるカワ・ともいし（文字は「こおりを狙え！」） |

   セリフは仮の案です（`new/src/presentation/lcd/cutinCast.js`）。

2. **前のカットインが残っていたら消す**：新しいカットインが出るとき、前のカットインを右へすばやく（0.2秒）はけさせて消します。チャンスのカットイン・天国のカットイン・「こおりを狙え」・必殺技のカットインのどれでも同じです。

3. カットインのキャラは、背の高さに合わせて大きさをそろえました（小さい絵のキャラも顔が帯に収まるように）。
