## 内部処理の担当にお願いすること（1つ）

**`notice` に `iwakan`（違和感演出）を足してください。**

| kind | データ | いつ |
|---|---|---|
| `iwakan` | `{ timing: 'lever', effect }` | AT 中（特化ゾーン中を除く）のレバー |

- 期待度に関わるので、出すかどうか・どの `effect` かは内部処理の抽選です。ボーナスか特化ゾーンに当たったゲームで出やすく、当たっていないゲームでもたまに出してください（ガセ）。
- 項目の名前は `effect` です（イベントの種類を表す `type` と重なると消えてしまうため）。
- `navGlitch` と `navQuestion` は、そのゲームに押し順ナビ（`at:game` の `nav`）があるときだけ出してください。
- 仮組は「当たったゲームで 40%・当たっていないゲームで 1/40、種類は均等」にしてあります【仮】（`logic.patch`）。
- 約束は `docs/events.md` v0.4（`docs.patch` にも入っています）。

| effect | 見せ方 |
|---|---|
| `'navGlitch'` | 押し順ナビの数字がバラバラに入れかわってから落ち着く |
| `'navQuestion'` | 押し順ナビが一瞬「？」になる |
| `'noise'` | 液晶に横線と砂嵐のノイズが走る |
| `'mute'` | BGM が一瞬止まる |
| `'freeze'` | 液晶の絵が一瞬止まる |
| `'invert'` | 液晶の色が一瞬（2回）反転する |
| `'button'` | PUSH ボタンが勝手にチカチカ光る |
| `'lever'` | レバーの音が低く鈍い音になる |
