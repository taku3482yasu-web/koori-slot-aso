# 直したもの：play.html が真っ白になった（2026-10-21）

演出側（ユーザー・Claude）が 2026-10-21 に直した部分だけを、このフォルダにまとめました。
リポジトリの main にはもう入っています。このフォルダは「何が変わったか」を見るためのものです。

## 内部処理の担当にお願いすること

**ありません。** ゲームの中身とイベントは変わっていません。`play.html` を作る道具（`tools/build-file.mjs`）だけの直しです。

## 何が起きたか

- `handoff/2026-10-21_judge-kill/` の変更のあと、`play.html`（ダブルクリックで遊ぶ1つのファイル）を開くと何も表示されなくなった。
- 原因：`tools/build-file.mjs` は、スクリプトを `html.replace('</body>', スクリプト + '</body>')` で HTML に入れていた。置きかえを文字列で渡すと、その中の `$&` は「見つかった文字（`</body>`）」という記号として読まれる。ビルドで小さくしたスクリプトの中にたまたま `$&&(...)` ができて、スクリプトの途中に `</body>` が入り、スクリプトが壊れていた。
- GitHub Pages（ネットの版）は別のビルドなので、影響はなかった。

## 直したこと

- 置きかえを関数で渡すようにした（`html.replace('</body>', () => …)`）。関数で渡すと `$&` などは記号として読まれない（`tools.patch`）。
- `play.html` のスクリプトが壊れていないかを確かめるテストを足した（`new/tests/playfile.test.js`。`npm test` で動く）。壊れていた版の `play.html` でこのテストが失敗することも確かめた。

`.patch` は `git diff` の形です。`+` で始まる行が足した行、`-` で始まる行が消した行です。
