## 内部処理の担当にお願いすること（1つだけ）

**`at:end` に `trophy`（設定示唆トロフィーの色）を足してください。**

| trophy | 色 | 示唆 |
|---|---|---|
| `'white'` | 白 | 示唆なし（設定1以上） |
| `'blue'` | 青 | 設定2以上 |
| `'green'` | 緑 | 設定3以上 |
| `'purple'` | 紫 | 設定4以上 |
| `'red'` | 赤 | 設定5以上 |
| `'rainbow'` | 虹 | 設定6確定 |
| `null` | 出ない | |

- 前作のスロット（こおりくんの大冒険 第1弾）と同じトロフィーです。AT 終了画面の左下に落ちてきます。
- 台の設定より上の色は出さないでください。出る率と色の振り分けは内部処理で決めてください。
- 仮組は前作と同じ値にしてあります（出る率 50%。設定ごとの色の重みは `logic.patch` の `show.trophy`）。
- 約束は `docs/events.md` v0.3 の `at:end`（`docs.patch` にも入っています）。

図鑑・実績・記録は、演出側がイベントを見て数えるだけなので、内部処理に足すものはありません。
使うイベントは次のとおりです（どれも今の約束のまま。データも変えていません）。
`lever` `stage` `zencho:start` `zencho:battle` `heaven` `tenjo` `at:direct` `bonus:start` `at:start` `at:add` `at:boss` `at:judge` `tokka:start` `tokka:end` `at:end`

## 中身

| ファイル | 中身 |
|---|---|
| `new/src/presentation/collection/collection.js` | 図鑑・実績・記録。イベントから「会った・倒した・見た」を数えて、ブラウザ（localStorage）に保存する |
| `new/src/presentation/collection/profiles.js` | 図鑑のキャラクターの説明文（前作の説明をもとに今作の設定に合わせたものと、今作の新キャラ） |
| `new/src/presentation/components/Zukan.jsx` | 図鑑の画面（キャラクター・技・エピソード・トロフィー・終了画面・実績・記録） |
| `new/tests/collection.test.js` | 図鑑のテスト |
| `presentation.patch` | 今ある演出のファイルに足した部分（`App.jsx`：図鑑のボタン・実績のお知らせ・筐体を画面に収める / `game.js`：イベントを図鑑に渡す / `lcd/at.js`：トロフィーの絵・技の名前 / `lcd/director.js`：トロフィーの表示と音・見たエピソードを知らせる / `styles.css`：図鑑の見た目） |
| `logic.patch` | 仮組の内部処理に足した部分（トロフィーの抽選）。本物の内部処理を作るときの参考 |
| `docs.patch` | 書類に足した部分（`docs/events.md` の `trophy`、画面設計書 1章・10章） |

`.patch` は `git diff` の形です。`+` で始まる行が足した行、`-` で始まる行が消した行です。
