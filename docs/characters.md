## 1. 世界観・ストーリー（決定）

- **舞台**：やまぐっち（山口）とおかおか（福岡）の境目に、突然「**ASO摩天楼**」が現れた。
- **うわさ**：摩天楼には **ASO四天王** と **大魔王ASO** がいて、大量の金銀財宝を持っているらしい。
- **こおりくんの目的**：こおりくんはお金がなく、おにおにに借りたお金を返せない。そこで財宝を手に入れて借金を返すため、仲間を連れて摩天楼の突破に挑む。
- **仲間**：おにおに・やすさん・たむさん・だけさん（チーム名「ばりきつよめ」）
- **ライバル**：財宝をねらって、ほかに 3 チームが摩天楼に挑んでいる。
- **敵**：摩天楼には、住み着いた敵キャラと四天王がいる。

## 4. ライバルチーム（決定）

前兆の中間階層で戦う相手です。

- 決定：強さは **5DX → ASK-3 → お願いマッスル** の順に上がり、**お願いマッスルがいちばん強い**。
- 決定：**お願いマッスルが出たら熱い**。
  - 期待度は 5DX ＜ ASK-3 ＜ お願いマッスル。
  - 内部：本物の前兆ほど強いチームが出やすくなるように、内部処理が相手を抽選します。
