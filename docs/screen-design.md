# 画面設計書 ― こおりくんの大冒険～最凶のASO摩天楼への挑戦～

版: v0.4（2026-10-20）
キャラクターは [キャラ設計書](characters.md) にまとめています。
絵つきで読むときは `docs/design.html` を開いてください（作り直しは `node tools/build-design.mjs`）。

- 「決定」：ユーザーが指定したもの
- 「仕様書」：内部処理の仕様書（AT機 仕様書 v0.1・2026-10-20 更新版）で決まっていること
- 「案」：Claude の仮の案です。直してください
- 「内部」：内部処理（logic）が抽選・決定し、イベントで演出側に伝えるもの

**演出と内部処理の分け方**：
- どの演出を出すか（期待度に関わるもの）は**内部処理**が抽選し、イベントで伝えます。
- 画面・動き・音は、演出側がそのイベントを受けて作ります。
- イベント名はこの書類では仮のもので、正式な一覧は docs/events.md にまとめます。

**画面イメージについて**：
- 案：演出を作るときの見本として、Claude が描いた仮の絵です。
- 文字・数字は例で、色や配置を直したいときは教えてください。
- 液晶は 320×180 ドット（16:9）で描いています。

**v0.4 で足したこと**（仕様書の更新に合わせた）：
- リールにこおりくん図柄、レア役の停止形、入賞ライン（2章）
- 天国の 0G・50G 煽り、ガセ前兆からの昇格、天井は BIG 確定（3章）
- ボーナスのゲーム数、「こおりを狙え」カットイン、1G連の振り分け（4章）
- AT の継続演出、ストックの放出の順番、上乗せなし（5章）
- 特化ゾーンの「復活」、+5G、ストック（6章）

### 2-2. リールの止まり方（仕様書）

- **目押しはいりません**。当たった役は必ず引き込むので（取りこぼしなし）、目押しが苦手な人でも全部の演出が見られます。
- 押した位置に近いところで止まります。実際の滑りは数コマで、中・右リールは最大 10コマ滑ります。
- **入賞ラインは中段 1本**です（ボーナス図柄とこおりくん揃い）。
- 押し順ベルあり（ナビあり。ナビなしで押し順をまちがえると取りこぼす）。
- リール配列は v1.0（各 21コマ）。配列の表は仕様書を見てください。

## 3. 通常時

### 3-1. ステージ（決定）

液晶には摩天楼の**今いる階**を出します。階で内部状態がわかります。

```mock
stage-low 低確：1〜10階（明るいロビー）。左下でふるカワがナビをする
stage-high 高確：11階以上（夕方）。奥に住み着いた敵の影
stage-super 超高確：22階（ダイシの間）。夜で、奥に四天王の影
stage-maou 超高確：56階（大魔王の間）
```

| 内部状態 | ステージ（階） | 見た目（案） |
|---|---|---|
| 低確 | 1〜10階 | 明るいロビー・下の階 |
| 高確 | 11階以上（22・33・44・55・56階は除く） | 夕方。窓の外が高くなる |
| 超高確 | 22・33・44・55階（四天王）、56階（大魔王ASO） | 夜。その階の四天王・魔王の影が奥に見える |
| 前兆 | 摩天楼中間階層（前兆専用） | 3-4 を参照 |

- 決定：**ふるカワがステージのナビ役**です（前作から続投）。案：左下に出て、階の説明などをしゃべります。
- 決定：**階の表示で状態が確定します**（ずれることはありません）。
- 仕様書：AT 中も低確・高確・超高確があります。
  - 案：AT 中は階を出さず、こおりバトルRASH の画面のままにします（状態は見せない）。
- 内部：階は内部処理が状態に合わせて決めます。
- 案：状態が変わったときやレア役のあとに、エレベーターで階が動く演出を出します。
- 案：高確・超高確からハズレで転落したときは、エレベーターで下の階へ戻ります。

### 3-2. 魔天ゾーン（決定）

- ゾーン（0・100・…・700G）に入っている間は、**画面のまわりに黒い靄**が出ます。
- 内部：ゾーンの出入りはイベントで伝えます。

```mock
zone-maten 魔天ゾーン：画面のまわりに黒い靄
```

- 仕様書：ゾーンの開始G に着いたら、当たりでもハズレでも**必ず前兆（30〜40G）に入ります**（ガセ前兆の発生率 100%）。
- 仕様書で「演出担当と詰めること」になっています：靄を**モードに関係なく 100G ごとに出すか**（8章の質問）。

### 3-3. 天国の示唆（決定）

天国にいるときは、次のカットインが出るようになります。

- シーシャ・ナイテイ・ナイナイ
- シーシャ・ナイテイ・アルアル

```mock
heaven-naitei ナイナイのカットイン
heaven-aruaru アルアルのカットイン（案：アルアルのほうが期待度が高い）
```

- 仕様書：天国は 100G 以内に当たります。前兆の始まりは 0G 煽り（50%）か 50G 煽り（50%）です。超天国は 50G 以内で、0G 煽りだけです。
- 仕様書：ふつうのモードには 50G から始まるゾーンがないので、**50G からの煽りは天国確定**です。
  - 案：50G で魔天ゾーンの靄が出たら、ナイナイかアルアルのカットインも出して、天国確定を知らせます。

### 3-4. 前兆（決定）

1. 前兆（30〜40G）に入ると、ステージが**摩天楼中間階層**に移ります。
2. 中間階層では**ライバルチームとのバトル**になります（連続演出）。
3. 最後に、相手チームを倒せば**ボーナス確定**、倒せなければ**ガセ**です。
4. 本物の前兆とガセ前兆は、途中まで同じ見た目です。

```mock
zencho-battle 中間階層でライバルチームと対決（例：チーム5DX）
zencho-win 撃破 → ボーナス確定。そろえる図柄を出す
zencho-lose 撃破ならず（ガセ）。例：チームASK-3 に負けた
```

- 決定：ライバルチームの強さは **5DX → ASK-3 → お願いマッスル** の順に上がり、**お願いマッスルがいちばん強い**。
- 決定：**お願いマッスルが出たら熱い**（期待度は 5DX ＜ ASK-3 ＜ お願いマッスル）。
- 案：バトルの流れ
  1. 中間階層に入る
  2. 相手チームが登場（出たチームで期待度がわかる）
  3. 連続演出（1戦目・2戦目・3戦目のように数回の勝負）
  4. 最後のゲームで決着
- 内部：相手チーム・連続演出の回数・期待度の演出は内部処理が抽選します。
- 仕様書：前兆中は中間階層にいるので、**高確・超高確かどうかはわかりません**。
- 仕様書：ガセ前兆の途中でレア役からボーナスに当たると、その前兆が本物に変わり、前兆の終わりで当たります。
  - 案：見た目は変えず、そのままバトルで勝ちます。
  - 内部：変わったときは、それ以降の連続演出を当たりの流れに抽選し直します。
- 仕様書：本物の前兆の途中でレア役からもう一度ボーナスに当たると、**1G連のストック**になります（4-4）。前兆中には見せず、ボーナスの終わりで知らせます。

### 3-5. 天井（決定）

- 天井（777G、モード C は 400G）に着くと、**ナイナイかアルアル**が出てきて当たり演出になります。
- 仕様書：天井は **BIG 確定**で、ちょうど 777G（C は 400G）で当たります。
- 仕様書で「演出担当と詰めること」になっています：アルアルが出たときの特典をつけるか（8章の質問）。

```mock
tenjo 天井到達（アルアルが出たとき）
```

### 3-6. 期待度のある演出（決定：パチンコ・スロットの演出を参考にする）

```mock
cutin-colors カットインの色：青 ＜ 緑 ＜ 赤 ＜ 金 ＜ 虹（確定）
```

| 種類 | 中身 |
|---|---|
| カットイン | 色の順：青 ＜ 緑 ＜ 赤 ＜ 金 ＜ 虹（確定）（パチンコ版のこおりカットインと同じ並び） |
| セリフ | 文字色の順：白 ＜ 青 ＜ 緑 ＜ 赤 ＜ 金 |

### 3-7. AT直撃（決定）

4. 「**こおりいきていける！**」の文字とともに、こおりくんが**虹色に光る**

```mock
chokugeki AT直撃：ノイズ → 暗転 → 「こおりいきていける！」でこおりくんが虹色に光る
```

## 4. 疑似ボーナス

### 4-1. 種類（決定・仕様書）

| ボーナス | 図柄 | ゲーム数 | AT 当選（目安） | 背景 | 中身 |
|---|---|---|---|---|---|
| BIG | 7・7・7 | 50G | 約40% | 黄金 | キャラ解説・ステージ解説などが流れる |
| REG | 7・7・BAR | 20G | 約20% | 銀色 | 案：BIG と同じ解説の短い版 |
| エピソードBIG | BAR・BAR・BAR | 50G | **AT 確定** | 案：夕焼けの摩天楼 | こおりくんのストーリー、ほかのチームのストーリー |

```mock
big BIG：黄金の背景にキャラ解説
reg REG：銀色の背景にステージ解説
epbig エピソードBIG：こおりくんのストーリー（例：第1話「借金」）
```

- 仕様書：弱スイカから当たったときは、モードに関係なくエピソードBIG 確定です。
- 仕様書：ボーナス中のレア役では上乗せしません（AT の抽選だけ）。

### 4-2. エピソードBIG の中身（決定）

- こおりくんが摩天楼へ行くまでのあらすじ（借金 → うわさ → 仲間集め）
- 摩天楼に挑戦している様子
- ほかのチームの様子と、挑戦する理由（背景）

案：エピソードは何話かに分けて、引くたびに次の話へ進みます。全部見たら1話に戻ります。

- 作ったもの（2026-10-20）：Claude のたたき台で全5話（第1話「借金」・第2話「うわさ」・第3話「仲間集め」・第4話「ライバル」・第5話「四天王」）。文章は `src/presentation/lcd/bonusStory.js`。話の中身を指定するときは教えてください（8章の 9）。

案：エピソードBIG は AT 確定なので、最後のゲームで必ず「こおりを狙え」→ こおりくん揃いにします。

- 今は、始まりから右上に「AT確定」を出し、終わりに「こおりバトルRASH へ！」と出しています。最後のゲームの「こおりを狙え」は内部処理がイベントを出す必要があるので、内部処理の担当と相談します。

### 4-3. ボーナス中の AT 当選の告知（決定・仕様書）

ボーナス中にレア役で AT に当たったら、「**こおりを狙え**」カットインを出して、**こおりくん図柄揃い**で知らせます。

1. 「**こおりを狙え**」カットイン
2. こおりくん図柄が中段にそろう
3. こおりくんが**虹色に光るインパクトフラッシュ**
4. 「**AT確定**」の文字と、**専用の当たり音声**

```mock
koori-nerae 「こおりを狙え」カットイン
bonus-at こおりくん揃い → 虹色のインパクトフラッシュ → 「AT確定」
```

- 仕様書：「こおりを狙え」には**ガセもあります**（テンパイハズレ）。
- 仕様書：**押し順で、確定がわかるタイミングが変わります**。
  - 順押し（左 → 中 → 右）：第3停止まで引っ張る
  - 中押し：中リールにこおりくんが止まった時点で確定（1確）
  - はさみ押し：左右でテンパイしたら確定（2確）
- 内部：カットインの色と、色ごとの成功率は内部処理が決めます（成功率は未定）。
  - 案：色は 3-6 のカットインと同じ並び（青 ＜ 緑 ＜ 赤 ＜ 金 ＜ 虹）にします。
- 案：成功したら、そろった瞬間（押し順で決まるタイミング）にフラッシュと音を出します。
- 作ったもの（2026-10-20）：確定のタイミングは、演出側がリールの出目（中段のこおりくん）で判定しています。順押しで左・中がこおりくんのときは「テンパイ！」。そろわなければ「…」。「AT確定」の音声は、まだ効果音で代わりにしています（8章の 10）。

### 4-4. ボーナスのストック（1G連）（決定・仕様書）

- ボーナスが終わるときに「**ボーナス確定**」と出して、もう一度 7 をそろえます。
- 仕様書：1G連のボーナスは **BIG 85%・エピソードBIG 15%**（REG はありません）。
- 仕様書：1G連は**何個でもストックできます**。
  - 案：2個以上あるときは「ボーナス確定 ×3」のように数を出します。
- 内部：次のボーナスの種類は内部処理が決めます。

```mock
bonus-stock ボーナス終了時の「ボーナス確定！」
```

## 5. AT「こおりバトルRASH」（決定）

### 5-1. 画面

- 仕様書：**初期ゲーム数は 50G**、純増は約3枚。
- **残りゲーム数**：いつも表示しておきます。
- **残りが少なくなったとき**：残り 10G・5G などで、残りゲーム数を大きな文字で知らせます。
  - 案：大きく出すのは 10・5・3・2・1G のとき。
- 作ったもの（2026-10-20）：突入の画面、残りゲーム数、10・5・3・2・1G の大きな数字、押し順ナビ（リールの上と液晶の両方）。
- **押し順ナビ**：リールの上に押す順番（1・2・3）を出します。

```mock
at-main AT の画面：右上に残りゲーム数、リールの上に押し順ナビ（例：中 → 右 → 左）
at-count 残り 5G のお知らせ
```

### 5-2. 上乗せ（決定）

- レア役のときは、**仲間たちが攻撃する演出**が出て、上乗せしたゲーム数を表示します。
- 大きい上乗せのときは、**おにおにか、こおりくん**が攻撃します。
- 決定：攻撃する相手は**摩天楼に住み着いた敵**です。
  - 強い敵ほど上乗せが多く、**ゴールド金面犬がいちばん多い**。

## 6. 上乗せ特化ゾーン（決定・仕様書）

- 1セット3G。3G のうちにリプレイ以上（リプレイかレア役）を引けば次のセットへ続きます。
- 1G ごとに **5G 以上**の上乗せがあります。

演出は2パターンあります。

| パターン | 結果の出し方 | 継続確定の見せ方 |
|---|---|---|
| 魔王の褒美 | 3G が終わってから、上乗せと継続の結果をまとめて出す | 継続確定（強レア役・中段チェリー）が入っていたら、**虹フラッシュ**が出て継続 |
| こおり大腸炎 | 1G ごとに上乗せを出す | こおりくんが虹色に光り、まわりの炎が虹色になったら「**確定**」と出る |

```mock

zone-daichoen こおり大腸炎：1G ごとに上乗せを出す
zone-daichoen-kakutei こおり大腸炎：炎が虹色になって「確定」
```

- 決定：**どちらのパターンにするかは、プレイヤーが選びます**。
  - 案：ストック告知のあと、特化ゾーンが始まる前に選ぶ画面を出します。
  - 案：停止ボタン（左・右）か画面のタップで選び、PUSH で決めます。
  - 案：前に選んだほうを最初に選んでおきます。
  - 案：10秒たったら、そのとき選んでいるほうで始めます。
  - 選んだパターンで変わるのは見せ方だけで、上乗せや継続の確率は同じです。

```mock

```

- **特化ゾーン当選時の特殊な演出**：当選したゲームですぐにストックを知らせます。
  - 案：液晶が一瞬止まり（フリーズ風）、黒い画面に「特化ゾーン ストック！」と出て、確定音が鳴る。

  - 中段チェリーを引いたら、次のセットとその次のセットの継続が確定（上乗せも 300G か 500G）
