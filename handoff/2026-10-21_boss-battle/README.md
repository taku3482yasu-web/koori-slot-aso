# 追加分：AT 中のボーナスのバトル画面・仲間の攻撃・ラストジャッジ（2026-10-21）

演出側（ユーザー・Claude）が 2026-10-21 に足した部分だけを、このフォルダにまとめました。
リポジトリの main にはもう入っています。このフォルダは「何が増えたか」を見るためのものです。

## 内部処理の担当にお願いすること（3つ）

### 1. `at:bossAttack`（レア役のときの仲間の攻撃）を足してください

| type | データ | いつ |
|---|---|---|
| `at:bossAttack` | `{ boss, move, result, color, shout }` | AT 中のボーナスで、特化ゾーンに当たる前のレア役（チャンス目を含む）のゲームのレバー。「こおりを狙え」のゲームと最後のゲームでは出さない |

| データ | 中身 |
|---|---|
| `move` | `'cutin'`（攻撃のカットイン）/ `'special'`（必殺技のカットイン。大ダメージ） |
| `result` | `'hit'`（当たる）/ `'guard'`（ガードされる。ガセ）/ `'dodge'`（よけられる。ガセ） |
| `color` | ダメージの文字と「畳みかけろ！」の色。`'white'` `'red'`（熱い）`'gold'` `'rainbow'`（**金・虹は特化ゾーン確定**）。`result` が `'hit'` でないときは `'white'` |
| `shout` | `true` なら仲間の吹き出し「畳みかけろ！」（見込みが高いときに出しやすく）。`result` が `'hit'` のときだけ |

- 期待度に関わるので、どれも内部処理の抽選です。攻めるキャラ・しゃべるキャラは演出側が選びます。
- 仮組は「このボーナスで特化ゾーンに当たるか（始まりで決めている）」で振り分けを変えています【仮】（`src/logic/config.js` の `show.bossAttack`）。

### 2. 最後のゲームの `at:boss`（敗北）を、`at:bossJudge`（ラストジャッジ）に置きかえてください

| type | データ | いつ |
|---|---|---|
| `at:bossJudge` | `{ boss, win, finisher }` | AT 中のボーナスで、特化ゾーンに当たらないまま最後のゲーム（残り 1G）に来たとき、そのゲームのレバー |

- `win`: 勝てば特化ゾーン当選（このあと `at:boss` の勝利は出さない。「こおりを狙え」も出さない）。負ければ今までの敗北と同じ。
- `finisher`: とどめの必殺技を放つキャラ。ふつうは `'koori'`（勝ちも負けもある）。**`'koori'` 以外（`'onioni'` `'yasu'` `'tamu'` `'dake'` とほかのチームのキャラ）は勝つときだけ**にしてください（出たら確定）。
- v0.5 までの「最後のゲームのレバーで `at:boss`（`final: true, win: false`）」は出さなくなります。
- 仮組は「当たるボーナスの 30% はラストジャッジで勝つ・勝つときの 45% は仲間が必殺技を放つ」【仮】（`show.bossJudge`）。

### 3. デバッグに `bossJudge(win)` を足してください

AT 中のボーナスを、次のゲームでラストジャッジにします（`win`: 勝つか）。

約束は `docs/events.md` v0.6（`docs.patch` にも入っています）。

## 足したもの（演出）

- **バトル画面**（画面設計書 5-3-1）：AT 中のボーナスで、PUSH ボタンか液晶のタップで、ボーナス画面（今までどおり。倒したら「勝利！」）と切りかえる。チームばりきつよめとほかの3チームが四天王・大魔王ASO に挑み、目まぐるしく戦い続ける（飛びこんで激突・技を撃つ・反撃をよける）。相手の体力のゲージつき。切りかえは演出側だけなので、内部処理の追加はいりません。
- **仲間の攻撃**：レア役で、仲間かこおりくんが攻撃のカットインか必殺技 → 当たる / ガード / よける →「〇〇に ダメージ！」と「畳みかけろ！」（赤は熱い・金と虹は確定）。
- **ラストジャッジ**（画面設計書 5-3-2）：残り 1G で、こおりくんと相手の一騎打ち → PUSH → 激突 → とどめの必殺技。こおりくんの技は防がれて反撃されることもある。おにおにやほかのキャラが「待たせたな！」と飛びこんで必殺技を放ったら確定。
- **おかランプの改善**（画面設計書 6章）：まんなかに8頭身のおかがっぱ（キレのすごいダンス。頭にランプ）、左右にいつものおかがっぱ。イベントは変わりません。
