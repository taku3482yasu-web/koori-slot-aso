# 追加分：特化ゾーン「おかランプ」（2026-10-21）

演出側（ユーザー・Claude）が 2026-10-21 に足した部分だけを、このフォルダにまとめました。
リポジトリの main にはもう入っています。このフォルダは「何が増えたか」を見るためのものです。

## 内部処理の担当にお願いすること（1つ）

**`tokka:game` に `hit`（このゲームでリプレイ以上を引いた）を足してください。**

| type | データ | いつ |
|---|---|---|
| `tokka:game` | `{ set, game, add, guarantee, hit }` | 特化ゾーンの1ゲーム（レバーのとき）。`hit`: このゲームでリプレイ以上（リプレイかレア役）を引いた＝自力継続の条件を満たした |

- 「おかランプ」では、リプレイ以上を引いたゲームでレバーの瞬間にランプが真っ赤に点灯します。そのために、レバーのときに `hit` が必要です。
- 100G 以上の上乗せでもランプが点灯し、25% くらいで虹色になります。これは今ある `add` を使って演出側が出し分けるので、追加はいりません。
- 仮組は「リプレイかレア役なら `hit: true`」にしてあります（`logic.patch`）。
- 約束は `docs/events.md` v0.5（`docs.patch` にも入っています）。

## 足したもの（演出）

- 特化ゾーンの見せ方を3つにしました（選ぶ画面は左から 魔王の褒美・**おかランプ**・こおり大腸炎。左・中・右の停止ボタンか画面のタップで選んで、PUSH で決める）。見せ方だけで、上乗せや継続の確率は同じです。
- **おかランプ**：
  - おかがっぱが頭の皿の上にランプをのせて、ミラーボールの下のダンスフロアで踊り続ける（BGM は踊れる曲）
  - リプレイ以上を引いたゲームは、レバーの瞬間にランプが真っ赤に点灯（「ピカッ！」）
  - 100G 以上の上乗せも点灯し、25% で虹色（「ピカーッ！！」で3桁の上乗せを告知）
  - ランプは次のゲームのレバーまで点いたまま。上乗せはリールが止まってから出す
